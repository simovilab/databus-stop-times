## Install recipe verified from scratch

Ran, in a fresh directory with a fresh `uv venv --python 3.12 .venv`:

```
uv pip install '<worktree>/packages/cli[core,record,train,serve,val]'
```

Produced a working `stoptimes --help`. `uv pip install` resolves the in-repo
`stoptimes-core`/`-record`/`-train`/`-serve`/`-val` packages against the workspace's
`pyproject.toml` (`[tool.uv.sources]` with `workspace = true`); a plain `pip install` would
not, since those names have no version pin or URL outside the workspace. Documented this
distinction in `docs/quickstart.md`'s install section and pointed to it from `docs/index.md`.
